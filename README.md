# 视频字幕取词工具 (Video Subtitle Word Grabber)

在屏幕上放一个**可自由移动 / 缩放**的半透明取词框,对准视频字幕。程序每 0.5 秒
自动截取框内画面 → OCR 识别(中英) → **智能流式去重** → 追加写入本地 txt。

适合做外语视频生词收集、字幕摘录等。纯 Python + tkinter,OCR 用 RapidOCR
(自带 PP‑OCRv4 中英模型,**无需安装 Tesseract**)。面向 Windows 10/11 + Python 3.10+。

---

## 快速开始

```bat
pip install -r requirements.txt
python video_word_grabber.py
```

或直接**双击 `启动取词.bat`**(会自动检测/安装依赖,并以无控制台窗口方式启动)。

操作:

1. 出现**控制面板**(置顶的小窗口)和**取词框**(绿色边框、中间透明)。
2. 拖取词框**顶部深色条**移动它;拖**右下角绿色 ◢ 手柄**缩放它。把中间透明区
   对准字幕那一条。
3. 在控制面板选好**字幕类型**(见下),可先点【测试一次】确认能识别到字。
4. 点取词框顶栏的 **▶ 开始**(或控制面板的【开始取词】)。识别结果实时进入列表
   并写入输出文件。再点 **■ 停止** 结束(会自动补记最后一句)。

输出默认是脚本同目录的 `取词结果.txt`,可在面板修改。

## 字幕类型(决定用哪种去重)

视频字幕"一个个出"的方式不同,去重策略也不同。在面板下拉框选择:

| 选项 | 适用 | 例子 |
| --- | --- | --- |
| **逐字增长(打字机)** ·默认 | 一句话逐字/逐词累加,显示完整后停留再换下一句 | `我 → 我们 → 我们一起走吧` |
| **滚动条/滑动窗口** | 像直播实时字幕,文字不断左移,只显示最后几个字 | `今天天气很 → 天气很好我们 → 好我们出去玩` → 拼接成整句 |
| **整句一次性出现** | 整句直接显示、停留、再换 | `Hello`(停留)→ `World` |

---

## 参数

| 参数 | 含义 |
| --- | --- |
| 取词间隔(秒) | 多久截一次图,默认 0.5 |
| 合并阈值 | 相似度高于此值的相邻识别视为同一句而合并。调高→更易判为不同句;调低→合并更狠。默认 0.78 |
| 每句前加时间戳 | 勾选后每行前加 `[HH:MM:SS]` |

## 智能去重做了什么

同一句字幕会在连续多帧反复出现,且每帧 OCR 可能因渲染抖动、单字误识、全/半角
标点差异而略有不同——它们其实是同一句,只应记录一次;反过来 `Chapter 1` 和
`Chapter 2` 字面很像却是两句。去重器(`SubtitleDeduper`)用单槽状态机处理:

- **噪声合并**:与"当前句"相似度 ≥ 合并阈值 → 同一句,保留最完整/最干净的一版。
- **容噪增长(关键)**:打字机字幕逐字出现时,即使**某一帧误识/漏识了一个字**,也能
  靠"头部锚定 + 有界编辑距离的近似前缀"判定为同一句在生长,而**不会**把一句话拆成
  `速度 / 速喥很 / 速度很快` 这样的碎片(只记最终的 `速度很快`)。
- **滚动拼接**:滚动条模式下,用相邻帧的"后缀==前缀"重叠把滑动片段拼成完整句子。
- **确认变化才提交**:出现明显不同的新句、或连续 2 帧空白(字幕消失)才把当前句写盘。
- **闪烁抑制**:字幕短暂消失又出现时,用"近乎精确 + 时间受限"的最近历史抑制重复,
  但**绝不**用模糊相似度去删一句字面相近的全新句(避免把 `Chapter 1/2/3/4` 误删成
  只剩一句这类静默丢数据)。
- 比较用的是规范化后的**比较键**(NFKC 统一全/半角、去空白与抖动标点、小写),
  写入文件的始终是**原文**,不会被改坏。

### 自测

去重逻辑内置 14 条流式对抗测试(打字机、逐词、夹噪声、漏字、滚动、滚动重置、
相近不同句、单字中文、合法重复、闪烁、整句、全空白),**无需 GUI / OCR 依赖**即可运行:

```bat
python video_word_grabber.py --selftest
# 14/14 全部通过 [OK]
```

## 技术要点(均已实测验证)

- **取词不含自身边框**:取词框中间用透明色键,真正透明且鼠标可穿透(可继续操作下方
  播放器);截图只抓中间透明区并向内收缩,绝不会把工具自己的边框/控件喂给 OCR。
- **DPI 缩放正确**:创建窗口前设置 Per‑Monitor‑V2 DPI 感知(并检查返回值),使窗口
  坐标与截图物理像素 1:1 对齐,解决 125%/150% 缩放下截图错位。
- **多显示器 / 负坐标**:用 `all_screens=True` 抓取整个虚拟桌面;窗口被最小化或拖出
  屏幕(`-32000` 哨兵坐标)时自动跳过该次截图,避免 OCR 一片黑。
- **不卡顿 + 不堆积**:OCR 在后台单线程运行,截图队列只保留最新一帧;某帧 OCR 偏慢
  时只丢旧帧,不会越积越慢。实测单次 OCR 约 100–160ms(1000×120 区域,CPU),
  0.5s 间隔有约 3× 余量。
- **落盘安全**:每记录一句即 flush + fsync,尽量避免断电丢数据。

## 已知限制

- `字幕类型` 是单一全局设置;同一段视频若混用多种字幕风格,需手动切换(或保持默认
  `逐字增长`,它对打字机 + 轻微漂移最稳)。
- 滚动拼接的重叠判定是精确匹配:若两相邻滚动帧的重叠区里恰好有一个字被误识,该次
  可能拼接失败(为避免把共享长公共子串的不同句误拼,这是有意取舍)。
- 透明穿透是 **Windows** 特性;macOS / Linux 上取词区可能不透明。
- 播放器若处于**独占式全屏**,置顶取词框可能不显示;改用窗口化全屏即可。
